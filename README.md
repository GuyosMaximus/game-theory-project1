### 🔹 שלב 0 — הגדרת מטרת ההרצאה וחלוקת התפקידים

## 🛠️ פירוט הרכיבים ותהליך הפיתוח

### 📊 רכיב 1: המצגת הלימודית — AntiGravity & HTML (שקד)

**🎯 מטרה:** מצגת אינטראקטיבית בת 11 שקפים (`index.html`) מעוצבת ברמה אקדמית/ניהולית, המלווה את ההרצאה מהיסודות ועד לרעיונות מתקדמים.

**📚 תוכן המצגת (`index.html`):**

1. **Slide 1:** שקף פתיחה מרהיב — "תורת המשחקים: איך לקבל החלטות בעולם שבו כולם מנסים לנצח".  
2. **Slide 2:** מהי תורת המשחקים? אינטראקציות חברתיות (תחרות עסקית, עומסי תנועה, יחסים בינלאומיים, דייטינג).  
3. **Slide 3:** היסטוריה על קצה המזלג — ג'ון פון נוימן, אוסקר מורגנשטרן וג'ון נאש.  
4. **Slide 4:** דילמת האסיר (הבעיה והתרחיש) \+ **הטמעת נגן ה-Video המומחש**.  
5. **Slide 5:** דילמת האסיר (תובנות והפרדוקס) — מרוץ חימוש, מלחמת מחירים בקמעונאות, הסכמי אקלים.  
6. **Slide 6:** משחק דוגמה: פוקר קון (Kuhn Poker) — מלכה (\$Q\$), מלך (\$K\$), אס (\$A\$) ובלוף כמנגנון רציונלי.  
7. **Slide 7:** גאווה ישראלית: חתני פרס נובל — **פרופ' ישראל אומן** (משחקים חוזרים) ו**פרופ' דניאל כהנמן** (כלכלה התנהגותית).  
8. **Slide 8:** סוגי משחקים מרכזיים (סכום אפס, סכום שאינו אפס, חד-פעמי vs משחק חוזר).  
9. **Slide 9:** שימושים בעולם האמיתי (תמחור אסטרטגי, Waze ו-AI, ניהול קונפליקטים).  
10. **Slide 10:** לקחי מפתח — 3 מסרים קצרים לחיים.  
11. **Slide 11:** סיכום ושאלות לדיון חופשי.


### 🎬 רכיב 2: סרטון 3D דילמת האסיר — Claude Code & Three.js (שקד)

**🎯 מטרה:** סרטון 3D דרמטי ודינמי מבוסס Three.js המציג את דילמת האסיר, הבחירה האסטרטגית, וסגירת הסורגים בשיווי משקל נאש.

**🧩 מבנה ואבולוציית הדרמה בסרטון:**

1. **Phase 1 (Two Interrogation Rooms):** שני אסירים יושבים בחדרי חקירה נפרדים, מעליהם מרחפים שלטי 3D מוארים: `SILENT` (כחול) ו-`TESTIFY` (אדום).  
2. **Phase 2 (The Choice):** האסירים מתלבטים, ובוחרים בו-זמנית ב-`TESTIFY` (להלשין).  
3. **The Trap & Nash Equilibrium:** הסורגים נסגרים מעליהם, והמסך מציג את התוצאה: **2 שנות מאסר לכל אחד** — שיווי משקל נאש.

**⚙️ תהליך הפיתוח והשיפורים ב-Claude Code:**

- **בניית סצנת 3D ראשונית:** תכנון תאורה דרמטית, שולחנות מתכת ודמויות low-poly.  
- **דחיסת לוח הזמנים (Time Compression):** קיצור הטיים-ליין מ-67 שניות ל-40 שניות לקצב מהיר ופוגעני.  
- **פישוט הנרטיב:** הסרת המטריצה המתמטית העמוסה מהסצנה כדי להתמקד בדילמה ובסורגים.  
- **פתרון בעיות ויזואליות:** הגדלת טקסטים, מניעת חפיתות (overlap), והגבהת הסורגים לגובה הכתפיים.  
- **ממשק נגן (UI Overlay):** הוספת כפתורי `Play / Pause`, `Restart`, ו-`Record WebM`.


### 🃏 רכיב 3: משחק Kuhn Poker — PyCharm & Python (גיא)

**🎯 מטרה:** משחק אינטראקטיבי ב-Python להדגמת **אסטרטגיות מעורבות**, **מידע חלקי** ו**בלוף** מול יריב ממוחשב המשחק לפי שיווי משקל נאש.

**📜 חוקי המשחק בקיצור:**

- 3 קלפים בלבד: Q \< K \< A.  
- כל שחקן מניח אסימון אחד (Ante) ומקבל קלף.  
- אפשרויות: Check, Bet, Call, Fold.  
- בשיווי משקל נאש, בלוף עם המלכה (Q) הוא חלק מאסטרטגיה רציונלית\!

## 🚀 מדריך הרצה והתקנה

### 📊 צפייה במצגת (HTML)

פתחו את הקובץ `index.html` בכל דפדפן (ניתן להשתמש במקשי המקלדת `←` / `→` או `Space` לניווט, ו-`F` למסך מלא).

### 🎬 צפייה בסרטון (3D / MP4)

ניתן להריץ את הקובץ `prisoners_dilemma.mp4` או לצפות בו ישירות בשקף 4 במצגת ה-HTML.

### 🃏 הרצת Kuhn Poker מתוך PyCharm

1. פתחו את PyCharm ← **File → Open** ← בחרו את תיקיית הפרויקט.  
2. ודאו שהוגדר Python Interpreter בגרסה 3.10+.  
3. הריצו את קובץ המשחק `Poker.py` או `app.py` (`Shift + F10`).
